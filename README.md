# 📊 Sales Data Analysis & Interactive Power BI Dashboard

## 📌 Project Overview
This project provides an end-to-end sales performance analysis designed to extract business insights regarding sales trends, regional distribution, profitability, and product category dynamics. 

The analytical workflow includes:
1. **Data Preprocessing & Cleaning**: Done using **Python** (handling missing values, data transformation, and feature engineering).
2. **Interactive Visualization**: Built using **Power BI** with DAX measures and custom visuals to track KPIs and provide actionable business recommendations.

---

## 🛠️ Tools & Technologies
* **Python**: Data Cleaning, Manipulation & Feature Engineering (Pandas / NumPy)
* **Power BI**: Data Modeling, DAX Measures, Visualizations, and Dashboard Design
* **Excel**: Data Source (`Sales_Analysis_Final_Project_RAW.xlsx`)
